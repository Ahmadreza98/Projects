# Comparison Operators
---
Comparison operators are one of the logical comparison methods in Python. With the help of these operators, you can create conditional, comparison, looping, etc. statements. The following are the types of operators introduced. Their output is often true or false.
### Greater than `>`
```python
1 > 2 -> res: False: F
2 > 1 -> res: True: T
```
###  Equal or Greater than `>=`
```python
1 >= 2 -> res: F
2 >= 2 -> res: T
```
###  lower than `<`
```python
1 < 2 -> res: T
2 < 1 -> res: F
```
###  Equal or lower than `<=`
```python
1 <= 2 -> res: T
2 <= 2 -> res: T
```
###  Equal `==`
```python
'Ali' == 'ali' -> res: F
'Ali' == 'Ali' -> res: T
1 == 2 -> res: F
2 == 2 -> res: T
```
###  Not equal `!=`
```python
1 != 2 -> res: T
2 != 2 -> res: F
```
