# Print
---
The first code a student learns in the Python language course is the `print` command to print `Hello World!` in the terminal. The `print` command has a simple structure, but is very useful. The types of its application methods are as follows:
###  Print Simple String
```python
print("This is a simple text.")
```
###  Print Number
```python
print(25)
```
###  Print  a Variable
```python
age = 25
name = "Jack"
print(age)
print(name)
```
###  Print Multi Variable with `,`
```python
name = "Jack"
age = 25
print(age, name)
```
###  Print Combine of Variables and Strings with `,`
```python
name = "Jack"
age = 25
print("Name:", name, "Age:", age)
```
###  Print Multi Text with `+`
```python
first_name = "Jack"
last_name = "Smith"
print(first_name + " " + last_name)
```
###  Print `f`- String
```python
name = "Jack"
age = 25
print(f"Name: {name}, Age: {age}")
```
###  Print in Multi Line
```python
print(this first line.\nthis second line.)
```
###  Print with Change Separate `sep='|'`
```python
name = "Jack"
age = 25
job = "teacher"
print(name, age, job, sep="|")
```
