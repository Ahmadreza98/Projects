# Prelude
This semi-repository contains C/C++ course notes. The exercises for each section of the notes are included in the exercises folder. And similarly, the projects are included in the projects folder. This course has two useful prerequisites:  

1. Installing [VSCode](https://code.visualstudio.com/). 
2. Installing [msys64](https://www.msys2.org/) as the **C/C++** language compiler in **VSCode**.

After installing **msys64**, to confirm, open *CMD*, enter the following command and press Enter.
```terminal
gcc --version
```
Its output is:
```terminal
gcc (GCC) 15.2.0
```
